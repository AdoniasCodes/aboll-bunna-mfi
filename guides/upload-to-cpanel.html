Put the Aboll Bunna site on cPanel

Do this only after the client says yes. It replaces their old WordPress site with the new one.

1. Make the zip

Open the Terminal app and paste this line, then press Enter:

cd /Users/eyoel/vibecoding/helper/aboll-bunna-mfi && pnpm zip

When it finishes it prints Ready: and a file path. That zip file is the whole website.

2. Back up the old site

  1. Log in to their cPanel.
  2. Click File Manager, then open the public_html folder.
  3. Select everything, click Compress, and download that backup zip to your computer. Keep it.
  4. Now delete everything inside public_html.

3. Upload the new site

  1. Still in public_html, click Upload and choose the zip from step 1.
  2. Go back, right-click the zip, click Extract, and extract into public_html.
  3. Delete the zip file from public_html.
  4. Open abollbunnamfi.com and abollbunnamfi.com/am/ in your browser. Both should load.
The hidden file .htaccess must be in public_html. In File Manager, click Settings and tick Show Hidden Files to see it.
